# ماژول‌ها و تنظیمات

کد به دو بخش تقسیم شده است:

| پوشه | چه چیزی | در پروژه‌ی دیگر |
|---|---|---|
| `src/modules/` | کد قابل استفاده‌ی مجدد: صفحه‌ها، کامپوننت‌ها، منطق رزرو، پنل‌ها | **همان‌طور کپی می‌شود** |
| `src/config/` | هر چیزی که مخصوص این باشگاه است | **برای باشگاه جدید عوض می‌شود** |
| `src/app/` | فقط مسیرها (route)؛ هر صفحه یک ماژول را نشان می‌دهد | کپی می‌شود |
| `public/` | لوگو، ویدیو و عکس‌ها | عوض می‌شود |

ماژول‌ها هیچ نام، رنگ، رشته یا قیمتی را مستقیم در کد ندارند؛ همه را از `src/config` می‌خوانند.

## تنظیمات یک باشگاه (`src/config`)

| فایل | محتوا |
|---|---|
| `site.ts` | نام برند، لوگو، عنوان و توضیح سئو، منوی بالا، ستون‌های فوتر، نام کیف پول |
| `venue.ts` | رشته‌ها و بازی‌ها، زمین‌ها، قیمت‌ها، ساعت کاری، بازه‌ی رزرو، قوانین لغو |
| `home.tsx` | متن‌ها و کارت‌های صفحه‌ی خانه: هیرو، آمار، امکانات، راهنما، سؤالات، بنر پایانی |
| `content.ts` | عکس‌های مجموعه، نظر بازیکن‌ها، آدرس و تلفن و اینستاگرام |
| `theme.css` | رنگ‌ها و فونت‌ها برای حالت روشن و تیره |
| `brand/logo-parts.json` | شکل لوگوی سه‌بعدی |

## ماژول‌ها (`src/modules`)

| ماژول | کار |
|---|---|
| `core` | نوع‌ها، فرمت اعداد و تاریخ شمسی، وضعیت کاربر و سبد، لایه‌ی API، کمک‌تابع‌های venue، داده‌ی نمونه |
| `ui` | دکمه‌ی سه‌بعدی، توست، دکمه‌ی تم، آیکون‌های سه‌بعدی، شمارنده |
| `layout` | ناوبار، فوتر، برند، Providers |
| `home` | بخش‌های صفحه‌ی خانه |
| `booking` | انتخاب رشته، رزرو و نقشه‌ی زمین، پرداخت |
| `auth` | ورود با کد پیامکی |
| `coaches` | صفحه و کارت مربی‌ها |
| `panel` | پنل بازیکن، منشی و ادمین، جدول زنده |
| `three` | لوگو و مدل‌های سه‌بعدی |

قانون وابستگی: `core` به هیچ ماژولی وابسته نیست. `ui` فقط به `core` وابسته است. بقیه از `core` و `ui` و `layout` استفاده می‌کنند و از `@/config/...` می‌خوانند.

## راه‌اندازی برای باشگاه جدید

1. پوشه‌های `src/modules` و `src/app` و فایل‌های پیکربندی پروژه را کپی کنید.
2. پوشه‌ی `src/config` را کپی کنید و همه‌ی فایل‌هایش را برای باشگاه جدید عوض کنید.
3. لوگو و رسانه‌ها را در `public/brand` و `public/media` بگذارید.
4. آدرس بک‌اند جدید را در `.env.local` با `NEXT_PUBLIC_API_URL` بنویسید.

### اضافه کردن یک رشته‌ی جدید

در `venue.ts` یک مورد به `SPORTS` اضافه کنید، زمین‌هایش را در `COURTS` و قیمتش را در `PRICING` بنویسید. صفحه‌ی رزرو (`/book/<id>`)، انتخاب رشته، قیمت‌ها، سانس‌های خالی، جدول زنده و گزارش‌های ادمین خودکار آن را نشان می‌دهند.

مدل سه‌بعدی هر بازی یکی از `padel`، `tennis` یا `volley` است (`model`). برای رشته‌ای با مدل جدید باید آن مدل را در `modules/three` بسازید.
