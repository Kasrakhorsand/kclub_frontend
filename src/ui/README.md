# ظاهر K Club (ui)

همه‌ی کامپوننت‌ها، صفحه‌ها، سه‌بعدی و CSS مخصوص **K Club**. این پوشه بین سایت‌ها مشترک نیست؛ سایت دیگر (مثلاً نور کلاب) ظاهر خودش را جدا می‌سازد و فقط از `src/engine` استفاده می‌کند. راهنمای موتور: [`src/engine/README.md`](../engine/README.md).

| پوشه | کار |
|---|---|
| `kit` | دکمه‌ی سه‌بعدی، توست، دکمه‌ی تم، آیکون‌های Steel Edition، شمارنده |
| `layout` | ناوبار، فوتر، برند، Providers |
| `home` | بخش‌های صفحه‌ی خانه |
| `booking` | انتخاب رشته، صفحه‌ی رزرو و نقشه‌ی زمین، پرداخت |
| `auth` | کارت ورود |
| `coaches` | صفحه و کارت مربی‌ها |
| `panel` | پنل کاربری؛ یک پوشه برای هر نقش (بازیکن، منشی، ادمین) با صفحه‌ها و CSS خودش. راهنما: [`panel/README.md`](panel/README.md) |
| `three` | لوگو و مدل‌های سه‌بعدی |
| `styles/` | استایل‌ها، یک فایل برای هر بخش (جدول زیر)؛ رنگ‌ها از `src/config/theme.css` |

متن و تنظیمات K Club در `src/config` است: `site.ts` (برند، منو، فوتر)، `home.tsx` (متن خانه)، `content.ts` (عکس، نظر، تماس)، `venue.ts` (زمین و قیمت، که موتور هم می‌خواند) و `theme.css` (رنگ‌ها).

## استایل‌ها (`src/ui/styles/`)

| فایل | چه چیزی |
|---|---|
| `base.css` | پایه: تایپوگرافی، چیدمان، دکمه‌ها (معمولی و سه‌بعدی)، کارت، فرم، برچسب، جدول، توست، آیکون‌ها، دکمه‌ی بازگشت |
| `layout.css` | برند، ناوبار، دکمه‌ی تم، فوتر |
| `three.css` | لوگوی سه‌بعدی هیرو |
| `home.css` | همه‌ی بخش‌های صفحه‌ی خانه |
| `booking.css` | انتخاب رشته، رزرو، نقشه‌ی زمین، پرداخت، اجاره |
| `auth.css` | کارت ورود |
| `coaches.css` | صفحه‌ی مربیان |

CSS پنل در پوشه‌های خود پنل است (`panel/<نقش>/<نقش>.css`). ترتیب import در `src/app/globals.css` مهم است: اول `base.css`، بعد بقیه. استایل جدید را در فایل همان بخش بنویسید؛ اگر بین چند بخش مشترک است در `base.css`.
